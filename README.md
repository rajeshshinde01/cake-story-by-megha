# Cake Story by Megha — React website

Production-oriented React + Vite website for Cake Story by Megha.

## Development

```sh
pnpm install
pnpm dev
```

## Production build

```sh
pnpm run check
pnpm run build
pnpm run preview
```

The deployable output is generated in `dist/` and can be hosted on any static platform.

## Structure

- `src/components/` — reusable navigation and Cake Builder components
- `src/data/content.js` — catalogue, flavours, gallery, reviews, FAQ and contact details
- `src/App.jsx` — composed page sections
- `public/assets/` — optimized brand and cake photography

Update business content in `src/data/content.js`. Do not edit the generated `dist/` files directly.
